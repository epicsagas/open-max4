# 1990년대 고증 팩

`web/public/data/era-1990s.json`의 근거 문서. 맥스가 시대에 맞는 말을 하도록 배경지식을 넣되,
매 턴 전부 보내지 않고 필요한 줄만 고르는 게 목적이다.

## 동작

```
사용자 입력 ──▶ era.ts: 컷오프 연도로 거르고 키워드로 매칭 ──▶ 고른 줄만 시스템 프롬프트에 삽입
```

- `always` — 컷오프 이하 항목은 매 턴 들어간다. 시대 감각을 잡는 최소 배경(전화, 도스, TV, 삐삐 등).
- `facts` — `keywords` 중 하나가 사용자 입력에 포함될 때만 들어간다. 기본 상한 6줄.
- `group` — 물가처럼 값이 갱신되는 계열. 컷오프 이하 **최신 1건만** 남긴다. 1998년 페르소나가 1995년 버스요금을 말하는 사고를 막는다.

`year`는 그 사실이 성립한 해다. 페르소나 컷오프보다 나중 항목은 아예 후보에서 빠지므로, "1994년 맥스"에게 IMF를 물어도 팩에서 근거가 나가지 않는다.

## 컷오프가 보장하는 것과 못 하는 것

**하드 컷오프 (코드가 강제, 보장됨)** — 팩에서 뽑는 줄. `year > cutoff`인 항목은 후보에서 아예 빠진다. 1994 모드에서 IMF·스타크래프트·핑클 항목은 프롬프트에 못 들어간다.

**소프트 가드레일 (프롬프트 지시, 보장 안 됨)** — 모델이 원래 학습한 지식. 시스템 프롬프트가 "1995년 이후는 모른다"고 지시할 뿐, 이를 가로채는 장치는 없다. 사용자가 캐물으면 모델이 2000년대 이야기를 흘릴 수 있다.

즉 컷오프는 **내가 무엇을 넣어주느냐**를 통제하지, **모델이 무엇을 아느냐**를 지우지 못한다. 후자를 막으려면 응답 후처리(연도별 금칙 고유명사 검사 + 재생성)가 필요하고, 지금은 없다.

## 토큰 비용

팩은 145항목·6,159자다. 전부 넣으면 매 턴 그만큼이 고정으로 나간다.
실제 시스템 프롬프트 길이(측정값):

| 모드 | 입력 | 길이 |
|---|---|---|
| 표준 | "안녕" | 186자 |
| 고증 1994 | "안녕" (매칭 없음) | 849자 |
| 고증 1994 | "요즘 무슨 노래 들어?" | 1,178자 |
| 고증 1995 | "어제 드라마 봤어?" | 1,154자 |
| 고증 1997 | "야구 누가 잘해?" | 1,163자 |
| 고증 1999 | 키워드 7개 폭탄 | 1,189자 |

팩이 2배로 커져도 턴당 비용은 거의 그대로다. `always` + 매칭 상한 6줄로 묶여 있기 때문이다. 팩을 통째로 넣는 것 대비 **5분의 1 수준**이고, 팩이 더 커져도 상한은 변하지 않는다. 한국어는 토크나이저마다 자당 토큰이 달라 자수로 적었다. 대략 1자에 0.7~1토큰으로 보면 된다. 상한은 `eraLines(pack, input, cutoff, limit)`의 `limit`으로 조절한다.

### 생활 공간 — 다방·노래방·록카페

- **다방**: 약속 장소이자 연락처. 레지가 주문을 받고 다방으로 전화가 걸려온다. 90년대 중반 대학가 다방·레스토랑이 록카페로 대거 전업했다.
- **노래방**: 1991년 4월 부산에서 시작(가라오케 기계 개조). 최초 등록업소는 부산 광안리 '하와이비치 노래연습장'. 1992년 서울에서 폭발 — 2월 60여 곳에서 10월 1,600여 곳으로 늘었다. 한 곡 300~500원.
- **록카페**: 술 마시며 춤추는 공간. 신촌 일대에만 100여 곳. 시끄러워 대화가 안 된다는 비판이 많았다.
- **당구장·만화방·오락실·비디오방**: 남는 시간을 보내는 기본 코스.

## 한계

프롬프트에 배경을 넣는 것은 모델에 대한 **강제가 아니라 유도**다. 위 「컷오프가 보장하는 것과 못 하는 것」에 적었듯, 팩 주입만 코드로 막히고 모델 자체 지식은 막히지 않는다. 팩이 하는 일은 "맞는 말을 할 재료를 준다"까지고, "틀린 말을 안 하게 한다"는 보장하지 않는다. 작은 모델일수록 더 샌다.

수치는 위 출처 기준이며 충돌 구간은 본문에 명시했다. 팩에 넣은 값은 보수적으로, 충돌이 크면 범위나 서술로 뭉뚱그렸다.
