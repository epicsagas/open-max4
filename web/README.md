# MAX 4.00 웹 실행

원본 준비 절차는 저장소 루트 [README](../README.md)를 먼저 보세요. 원본 프로그램과 데이터는 이 저장소에 포함되어 있지 않으며, 사용자가 본인 사본을 `ref/max4/`에 두고 `web/local/`로 추출해야 합니다.

`web` 디렉터리에서 정적 서버를 실행한 뒤 브라우저로 엽니다.

```sh
cd web
python3 -m http.server 8080
```

http://localhost:8080 에 접속합니다. `file://`로 직접 열면 브라우저 보안 정책 때문에 실행되지 않습니다.

## 화면

- **현대판**: Windows 3.1 풍 크롬(틸 데스크톱, 비벨 창, 남색 타이틀바)과 CRT 모니터 프레임(스캔라인, 비네팅)으로 꾸린 화면입니다. 추출한 원본 대화 데이터(`public/local/max4-pjm.json`)로 재구현한 엔진입니다. 인칭(PJM.001/002) 판별 후 비명사 키워드(PJM.013)를 검색해 대응 응답(PJM.011/012)을, 매칭이 없으면 폴백 풀(PJM.031/032)에서 고릅니다.
- **원본 DOS**: 사용자가 직접 만든 js-dos 번들(`public/local/max4.jsdos`)을 에뮬레이터로 실행합니다. 번들이 없으면 이 버튼만 동작하지 않습니다. `현대판으로` 버튼으로 돌아옵니다.

## BYOK (선택)

헤더의 `BYOK` 체크박스와 `BYOK 설정`에서 OpenAI 호환 엔드포인트·모델·API 키를 넣으면, 원본 응답 다음에 선택적 확장 답변을 붙입니다. 키는 탭 단위 `sessionStorage`에 저장되어 탭을 닫으면 사라지고, 엔드포인트·모델만 `localStorage`에 남습니다. 브라우저 저장소는 같은 오리진의 스크립트가 읽을 수 있으므로 공용 PC에서는 사용 후 `키 지우기`를 누르세요.

**모드**: `표준`은 맥스 말투만 잡습니다. `고증 1994/1997/1999`는 해당 연도까지만 아는 것으로 제약하고, `public/data/era-1990s.json`의 시대 배경에서 입력과 관련된 줄만 골라 프롬프트에 넣습니다. 근거와 출처는 `docs/era-1990s.md`에 있습니다. 프롬프트 수준의 유도라 컷오프 이후 지식이 새는 것을 완전히 막지는 못합니다.

**CORS 제약**: 공식 `api.openai.com`은 브라우저 직접 호출을 허용하지 않습니다. 브라우저에서 호출 가능한 곳(예: Ollama `http://localhost:11434/v1`, LM Studio, CORS를 허용하는 호환 게이트웨이)을 엔드포인트로 사용하세요.

## 데이터 해독 상태

`PJM.021/022/023`(명사 키워드와 명사 응답, `[0`~`[4` 조사 치환 템플릿)은 표준 JOHAB이 아닌 별도 인코딩으로 저장돼 있어 아직 완전 해독되지 않았습니다. 원본 바이트는 카탈로그에 그대로 보존되어 있으며, 해독 전까지 명사 입력은 폴백 풀로 응답합니다. 조사 분석 진행 상황은 `docs/decode-notes.md`를 보세요.

## 고지

BYOK 확장 응답은 LLM이 생성한 것이며 원저작자가 쓴 문장이 아닙니다.
화면에서 `[맥스 · 확장]`으로 구분됩니다. 이 프로젝트는 비공식 팬 복원물입니다.
